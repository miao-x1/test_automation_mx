图例说明

  • PK: Primary Key (主键)
  • FK: Foreign Key (外键)
  • UK: Unique Key (唯一键)
  • FK_UK: Foreign Key + Unique Key (外键+唯一约束)

关系说明

  • ||--o{: 一对多关系 (One to Many)
  • ||--||: 一对一关系 (One to One)

表关系

  • Task → ImageFile: 一个任务可以有多张图片，级联删除
  • Task → AnalysisResult: 一个任务对应一个分析结果，级联删除
  • Task → Script: 一个任务对应一个测试脚本，级联删除

业务流程

  1. 用户上传UI截图 → 创建Task + ImageFile
  2. 启动分析 → Task状态更新为processing
  3. Agent分析图片 → 创建AnalysisResult
  4. 生成测试脚本 → 创建Script
  5. 完成 → Task状态更新为success
