## ④ 用户操作流程

### 流程1：上传需求文档

```
用户点击顶部导航"上传中心"（或任意页面的"前往上传中心"按钮）
  → 进入上传中心页面
  → 拖拽需求文档到上传区域（或点击选择文件）
  → 系统自动识别文件类型为"需求"
  → 上传完成 → 任务列表显示"已完成"
  → 点击"查看" → 查看解析结果
  → 可选择"创建需求"将文档内容转为需求
```

### 流程2：上传Swagger文件生成接口用例

```
用户进入上传中心
  → 上传 Swagger YAML/JSON 文件
  → 系统自动识别类型为"Swagger"
  → 解析完成 → 显示接口数量和模块信息
  → 点击"生成接口用例"
  → 跳转到接口测试用例管理页面，自动创建对应用例
```

### 流程3：上传脚本文件

```
用户进入上传中心
  → 上传 .py/.js/.sh 等脚本文件
  → 系统自动识别类型为"脚本"
  → 解析完成 → 显示脚本概要信息
  → 可关联到对应测试用例
```

### 流程4：上传视频/图片

```
用户进入上传中心
  → 上传 .mp4/.avi 等视频文件或 .png/.jpg 等图片文件
  → 系统自动识别类型为"视频"或"图片"
  → 上传完成 → 可关联到需求或测试用例
  → 视频文件可触发AI分析（提取操作步骤）
```

### 流程5：上传Schema文件

```
用户进入上传中心
  → 上传 JSON Schema / XML Schema 文件
  → 系统自动识别类型为"Schema"
  → 解析完成 → 可用于接口测试数据生成
```

### 流程6：从其他页面跳转上传

```
用户在需求列表页看到"前往上传中心"按钮
  → 点击按钮
  → 跳转到 /upload-tasks（上传中心）
  → 完成上传操作
  → 可通过浏览器后退返回原页面
  → 或上传中心提供"返回上一页"按钮
```

## ⑤ 风险说明

| 风险项 | 风险等级 | 说明 | 缓解措施 |
|--------|---------|------|---------|
| 上传按钮删除影响操作效率 | 中 | 用户习惯在当前页面直接上传，跳转到上传中心增加了操作步骤 | 各页面"前往上传中心"按钮使用新标签页打开，不离开当前页面；上传中心完成后提供明确的返回引导 |
| 文件类型自动识别准确率 | 高 | 自动识别依赖文件内容/扩展名判断，可能误判 | 识别结果展示置信度；提供手动修正类型下拉框；低置信度时提示用户确认；无法识别时标记"识别失败"并提供手动选择 |
| 大文件上传性能 | 中 | 视频、大型Swagger文件可能上传缓慢或超时 | 支持断点续传；显示上传进度条；大文件分片上传；设置合理的超时时间和文件大小限制 |
| 上传中心与需求模块上传中心冲突 | 高 | 需求模块（REQUIREMENT_PRODUCT.md）也有上传中心，可能造成两个上传入口 | 统一为一个全局上传中心 `/upload-tasks`；需求模块的"上传中心"子菜单直接跳转到全局上传中心；删除需求模块内独立上传页面 |
| 上传任务列表数据量 | 低 | 长期使用后上传记录可能非常多 | 支持分页、筛选（按类型/状态/时间）、搜索；提供批量清理历史记录功能 |
| 并发上传限制 | 低 | 同时上传多个大文件可能导致性能问题 | 限制并发上传数量（如最多3个）；排队机制；上传中任务显示进度和取消按钮 |
| 文件安全 | 中 | 上传文件可能包含恶意内容 | 服务端文件类型校验；文件内容扫描；限制上传文件大小和格式；隔离存储上传文件 |
