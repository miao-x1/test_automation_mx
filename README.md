# test_automation_mx
基于 FastAPI、React、Playwright 和多 Agent 架构的 AI 自动化测试平台，支持需求分析、UI 元素识别、测试用例生成、脚本生成和自动化执行。
# Test Automation Platform

An AI-powered automated testing platform.

## Features

- 🤖 AI Requirement Analysis
- 🖼️ UI Element Recognition
- 📝 Automated Test Case Generation
- 🎭 Playwright Script Generation
- 🔍 RAG-based Test Knowledge Management
- 📊 Test Execution Management

## Tech Stack

### Backend
- FastAPI
- SQLAlchemy
- MySQL
- Milvus
- Neo4j

### Frontend
- React
- TypeScript
- Ant Design

### Testing
- Playwright
- Pytest

## Architecture

Requirement
↓
AI Agent Analysis
↓
Test Case Generation
↓
Script Generation
↓
Automated Execution
↓
Test Report
