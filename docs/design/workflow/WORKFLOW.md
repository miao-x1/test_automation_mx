# WORKFLOW.md — 生成→执行完整流程

## 流程A（默认）

```
需求
 ↓
AI生成
 ↓
测试用例（executable=true）
 ↓
人工修订（可选）
 ↓
立即执行
 ↓
报告
```

**关键点：无需套件，用例生成后即可执行。**

---

## 流程B（高级）

```
需求
 ↓
AI生成
 ↓
测试用例（executable=true）
 ↓
创建套件（手动/推荐）
 ↓
执行套件
 ↓
报告
```

**关键点：套件是可选的编排能力，不是必须步骤。**

---

## 流程C（定时）

```
套件
 ↓
Schedule（cron配置）
 ↓
自动执行
 ↓
报告
 ↓
通知
```

**关键点：定时任务基于套件，因为需要批量执行。**

---

## 三种流程对比

| 维度 | 流程A（默认） | 流程B（高级） | 流程C（定时） |
|------|--------------|--------------|--------------|
| 入口 | 测试用例 | 接口测试 | 定时任务 |
| 执行对象 | 单条Case | 套件(多条Case) | 套件(多条Case) |
| API | /execution/run/case | /execution/run/suite | Schedule |
| 触发方式 | 手动点击 | 手动点击 | cron定时 |
| 适用场景 | 快速验证 | 回归/冒烟 | 持续监控 |
| 用户 | 所有用户 | 高级用户 | 高级用户 |

---
