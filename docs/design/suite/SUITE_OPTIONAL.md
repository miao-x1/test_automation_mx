# SUITE_OPTIONAL.md — 套件降级为可选高级功能

## 核心原则

**套件禁止自动生成。套件是推荐能力，不是必须能力。**

## 菜单位置

```
接口测试
├── 用例管理
├── 套件（可选）    ← 明确标注"可选"
├── 执行中心
└── 报告
```

## 套件页面变更

### 删除

- 自动生成套件
- 自动发布套件
- 强制套件才能执行的提示

### 新增

| 按钮 | 行为 |
|------|------|
| 生成推荐套件 | 分析标签/模块/优先级/依赖，生成建议组合 |

### "生成推荐套件"行为

```
1. 分析用例：
   - 按标签分组（如"用户模块"、"订单模块"）
   - 按优先级分组（P0冒烟、P1回归）
   - 按依赖关系分组（上下游链路）

2. 生成建议：
   - 推荐套件1：用户模块冒烟（P0 + 用户标签）
   - 推荐套件2：订单模块回归（P1 + 订单标签）
   - 推荐套件3：全链路回归（按依赖排序）

3. 用户确认：
   - 选择要创建的套件
   - 可调整用例列表
   - 手动点击"创建"

4. 禁止：
   - 自动发布
   - 自动执行
```

## 套件模型约束

```json
{
  "suite_id": 1,
  "suite_name": "用户模块冒烟",
  "case_ids": [1, 5, 3, 12]
}
```

- 只保存 case_ids，不保存步骤
- 不覆盖用例内容
- 环境配置可覆盖（env/base_url/headers/variables）

## 用户引导

```
新手路径：
  测试用例 → 立即执行 → 查看报告

高级路径：
  测试用例 → 创建套件 → 批量执行 → 查看报告

定时路径：
  套件 → 定时任务 → 自动执行 → 报告
```
